# Skills

Reusable agent skills for GitHub Copilot and other compatible coding agents.

## Available skills

### PR Explainer

Explains a pull request in plain language so a reviewer can quickly understand its purpose, changes, impact, and open questions. It focuses on context and comprehension rather than nitpicks or a line-by-line code review.

Location: [`skills/pr-explainer/SKILL.md`](skills/pr-explainer/SKILL.md)

For GitHub Copilot, skills in a repository can be placed under `.github/skills/<skill-name>/SKILL.md`. This repository keeps distributable skills under `skills/` so they can be installed or copied into a project.
